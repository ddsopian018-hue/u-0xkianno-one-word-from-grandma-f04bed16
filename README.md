One word a grandma would text about AI: **chatgbt** — "ChatGPT" with the GPT→GBT typo she would actually make. Warm, a little baffled, tied to the one AI product she has heard of, and funny with no caption. `main.py` (pure standard library, deterministic) writes the word, and nothing else, to `entry.txt` in the output directory.

## Run it

```sh
python3 main.py
```
